# GeoAI Video Script Writer

Create teaching scripts that change how the viewer thinks, not scripts that merely read a document aloud.

## Core Principle

Start from the decision, not the model.

Do not open with definitions, software menus, code walkthroughs, or repository reviews.

Open with one of these:

- a surprising question
- a common misconception
- a real field problem
- a decision with consequences
- a contrast between assumption and reality

Preferred narrative:

`Hook -> Story -> Conflict -> Rethink -> Explanation -> Mental Model -> Application -> Takeaway`

## Default Audience

- GIS analysts
- Remote Sensing practitioners
- forestry and mangrove staff
- carbon-credit and MRV teams
- field-operation teams
- R&D staff learning GeoAI
- beginners with basic GIS knowledge

Use Thai unless requested otherwise. Keep useful English technical terms in parentheses.

## Episode Length

- Pilot: 2-4 minutes
- Standard lesson: 7-10 minutes
- Deep lesson: 12-15 minutes only when necessary

One topic per episode.

## Script Workflow

### 1. Define one learning outcome

Write:

> หลังดูจบ ผู้ชมสามารถอธิบายหรือตัดสินใจเรื่อง ______ ได้

Examples:

- explain why higher image resolution is not always better
- choose between Classification, Detection, Segmentation, and Regression
- explain why Accuracy alone is insufficient
- decide when Random Forest is more appropriate than Deep Learning

### 2. Write the hook

The hook must appear in the first 5-15 seconds.

Good patterns:

- “Accuracy 95% อาจอันตรายกว่า Accuracy 80% ได้อย่างไร?”
- “ภาพโดรน 2 เซนติเมตร อาจแย่กว่าภาพดาวเทียม 10 เมตรจริงหรือ?”
- “ถ้ามี AI แต่ผู้บริหารยังตัดสินใจไม่ได้ ปัญหาอยู่ที่โมเดลหรือคำถาม?”

Never begin with:

> สวัสดีครับ วันนี้เราจะมาเรียนเรื่อง...

### 3. Build a short realistic scenario

Include:

- goal
- assumption
- mistake or tension
- consequence

Prefer forestry, mangrove, carbon, drone, satellite, biodiversity, or field-operation contexts.

### 4. Reveal the conflict

Use contrasts such as:

- prediction vs decision
- accuracy vs usefulness
- detail vs suitability
- complexity vs evidence
- AI pattern recognition vs field context

### 5. Explain only what resolves the problem

Use:

- analogies
- one simple diagram
- before/after comparison
- one practical example
- one limitation

Avoid excessive definitions and jargon.

### 6. End with one reusable mental model

Examples:

- GeoAI Pyramid: Data -> Information -> Prediction -> Decision -> Action
- Simplest Useful Method: GIS Rule -> ML -> DL
- Output Decision Tree: Type -> Location -> Boundary -> Number -> Change
- Validation Ladder: Data -> Metric -> Map -> Field -> Expert Review
- Five Questions: Problem -> Data -> Label -> Output -> Validation

### 7. Apply to real work

Include at least one application:

- Sentinel-2 mangrove classification
- shoreline change
- canopy-cover monitoring
- drone tree counting
- biomass or carbon estimation
- restoration progress monitoring
- biodiversity evidence
- field-photo QA/QC
- GIS rule-based location checking

### 8. Close with three takeaways

Use no more than three points and end with a reflective question.

Example:

> งาน GeoAI ที่คุณกำลังทำ หยุดอยู่ที่ Prediction หรือพาไปถึง Decision แล้ว?

## Required Output

For each episode, provide:

1. Episode title
2. Learning outcome
3. Estimated duration
4. Full narration script
5. Scene-by-scene timecode
6. Presenter direction
7. Visual direction
8. B-roll list
9. Diagram list
10. On-screen keywords
11. Subtitle plan
12. Editing notes
13. Three takeaways
14. End question

Use this table:

| Time | Narration | Presenter/Visual | On-screen text | Subtitle | Editing note |
|---|---|---|---|---|---|

## Quality Gate

Before approval, verify:

- hook appears within 15 seconds
- there is one clear learning outcome
- the episode does not begin with a definition
- the story is relevant to the audience
- the mental model is easy to remember
- the conclusion supports a real decision
- no unsupported claim is presented as fact
